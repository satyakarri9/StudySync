# MIT Course Generator

An AI-powered course curriculum generator that creates comprehensive learning paths on any topic.

## Features

- **Topic Input**: Enter any subject you want to learn
- **Knowledge Level Selection**: Choose from Basic, Intermediate, or Expert
- **Duration Slider**: Set course length from 1-12 weeks
- **AI-Generated Content**: Uses OpenAI API to create structured curricula
- **Detailed Output**: Generates modules, topics, learning objectives, prerequisites, and assessments

## Getting Started

### Prerequisites

- Node.js 18+
- OpenAI API key

### Installation

```bash
npm install
npm run dev
```

### Usage

1. Enter your desired course topic
2. Select your knowledge level
3. Choose the course duration
4. Click "Generate Course"
5. Enter your OpenAI API key when prompted

## Tech Stack

- React 19
