# StudySync AI 🎓

> Transform Your Study Sessions with AI

A modern, beautiful web application for students featuring AI-powered learning tools, focus tracking, and gamified progress.

![StudySync AI](https://img.shields.io/badge/Built%20with-React-61DAFB?style=for-the-badge&logo=react)
![Tailwind CSS](https://img.shields.io/badge/Styled%20with-Tailwind-38B2AC?style=for-the-badge&logo=tailwind-css)

## ✨ Features

### 📚 LectureGPT
- Upload lecture audio/video/PDF files
- AI-powered transcription and analysis
- Auto-generated summaries and key concepts
- Practice questions and flashcards
- Related YouTube video recommendations

### 🎯 FocusFlow
- 25-minute Pomodoro study sessions
- Adaptive AI quizzes after each session
- Tab tracking with gentle focus reminders
- Real-time attention monitoring

### 📊 Analytics & Gamification
- Study streak calendar (GitHub-style)
- XP points and achievements
- Detailed progress charts
- Focus score tracking
- Subject-wise time breakdown

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ and npm

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd StudySync
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🎨 Design Features

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Routing**: React Router
- **Animations**: Framer Motion
- **State Management**: React Context API
